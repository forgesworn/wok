# Support and donations

Wok is maintained by TheCryptoDonkey as part of
[ForgeSworn](https://github.com/forgesworn). It is MIT-licensed software with
public source. The publisher runs no hosted relay and provides no relay
service.

## Get help

Open [an issue](https://github.com/forgesworn/wok/issues). Include the version
or commit, platform and a minimal synthetic reproduction. Remove secret keys,
real event content, private paths and relay addresses. For security-sensitive
reports, follow [SECURITY.md](SECURITY.md).

Support is best effort, without an uptime, response-time or production
support guarantee.

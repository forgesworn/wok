# Security policy

Wok has not received an independent security audit.

Please report vulnerabilities through GitHub private vulnerability reporting
for `forgesworn/wok`. If that is unavailable, contact the maintainer privately
rather than opening a public issue. Include the affected revision, platform,
reproduction and likely impact.

Never include real Nostr secret keys or private event content in a report.

Only the latest release and latest `main` revision are supported.
